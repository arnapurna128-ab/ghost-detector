# Ghost Beneficiary Detector - Odisha

Detects fake / duplicate beneficiaries in govt schemes using Python.

## What it does
- Duplicate Aadhaar detection
- Invalid Age (>110) detection
- Fake Phone detection

## How to Run
pip install streamlit pandas
streamlit run app.py
